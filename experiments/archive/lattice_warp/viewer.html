What does “preserve relationships” mean here?

  • Every original cell ID and value is recovered exactly. Original grid connections can be reconstructed from the cell indices.
  • Lengths, angles, and geometric nearest neighbors can change during the bend.
  • The picture shows an unwrapped shear. The stored array wraps shifted cells at the top and bottom, making the discrete transformation reversible.

The position experiment uses the A = 5, B = 3 bend and a fixed coordinate grid of 1/8 cell width. Values and IDs remain separately stored.

How to interpret this experiment and run your own data

The patterned example is deliberately constructed from curved, repeated bands. The encoder is given only the completed data, and searches a chosen family of bends. The noisy example replaces about 10% of cells with random bytes. The random example is a control. This shows what this particular mechanism can do; it does not prove a best possible encoding for all data.

Python performs every transform, compression measurement, and byte-for-byte recovery check before writing this page. The sliders select those measured cases. Animation interpolates between them for display; measurements update at each tested bend. The browser draws the cells using those Python-generated numbers.

Run python experiment.py --open. Add a cubic uint8 NumPy array with --input data.npy --size 32. Its axes are z, y, x. Try a different generated sample with --seed 123. Full measurements, checksums, and repeated-compression results are in results.json; the method and independent decoding example are in report.md.
